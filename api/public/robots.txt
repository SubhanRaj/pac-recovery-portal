# Path-specific Disallow rules on purpose, not a blanket "Disallow: /": Cloudflare injects its
# own "Allow: /" ahead of this file on this zone (see its managed AI-crawler block above this
# one, left as-is — blocking GPTBot/ClaudeBot/etc. is desirable for a gov portal). Per Google's
# robots.txt spec, an Allow and a Disallow of equal path length resolve in favor of Allow on a
# tie, so a blanket "Disallow: /" here could lose that tie against Cloudflare's "Allow: /" for
# compliant crawlers; a longer, path-specific Disallow always wins regardless.

Disallow: /verify
